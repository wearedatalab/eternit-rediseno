# Eternit Colombia · propuesta de rediseño

Demo navegable de la propuesta de DataLab para el sitio de Eternit Colombia.

## Opciones de home

- Home 1 · actual (v5): <https://wearedatalab.github.io/eternit-rediseno/>
- Home 2 · más gris: <https://wearedatalab.github.io/eternit-rediseno/inicio/gris/>
- Home 3 · más blanco: <https://wearedatalab.github.io/eternit-rediseno/inicio/blanco/>
- Home 4 · propuesta DataLab: <https://wearedatalab.github.io/eternit-rediseno/inicio/datalab/>

Desde cualquier página se pasa de una opción a otra con el menú «Opciones de home».

Es una demo: las páginas llevan `noindex` para que no salgan en buscadores y el ingreso de distribuidores es un prototipo que no envía ni guarda lo que se escribe. El visualizador de paredes sí genera simulaciones, con un tope diario.

Este repositorio solo tiene el sitio ya armado (HTML, CSS, JavaScript e imágenes). No se edita a mano: se vuelve a generar desde el proyecto de origen.

Marcas, fotos de producto y datos técnicos: Eternit Colombia. Diseño y desarrollo: DataLab.
